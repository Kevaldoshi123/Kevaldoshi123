### 👨‍💻 About Me

I am a Software Engineer who believes that **to truly secure a system, you must first know how to build it—and then how to break it.** 

With a strong foundation in modern software engineering and asynchronous backend pipelines, I am actively focusing my career on **Cybersecurity, DevSecOps, and Application Pentesting**. I combine a builder's mindset with security-first thinking to architect robust systems, identify vulnerabilities, and engineer defensive solutions.

- 🔭 **Currently Building:** [**SentroniX**] — An AI-Driven Purple Team Cybersecurity Platform running SAST/DAST/SCA inside isolated Docker containers.
- 🌱 **Currently Learning:** Deepening my expertise in Vulnerability Research, Penetration Testing, and automating DevSecOps CI/CD pipelines.
- 💼 **Freelance:** I take on select freelance projects in **DevOps (CI/CD, Docker)** and **Graphic/UI Design**.
- 💬 **Ask me about:** Python, Docker, Celery/Redis pipelines, and integrating security scanners (OWASP ZAP, Nuclei) into workflows.
